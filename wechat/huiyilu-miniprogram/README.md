> 产品文档（产品界定、推进顺序与分工、用户行为漏斗、验收用例）为内部资料，随交付包提供，未公开到本仓库。
> 本小程序与产品文档完全对齐：双模式发起（本人自述 / 子女代发起）、受托开场、意愿先行、一次一问、徘徊只问不判、第一人称零添加成稿、老人点头定稿。

## 一、架构

```
微信小程序（原生 WXML/WXSS/JS）
  ├── 欢迎页：双模式入口
  ├── 访谈页：聊天（内部滚动）、语音输入、老照片上传、设置面板、回忆录面板
  └── 云函数 chatProxy：代理 DeepSeek API（Key 只存云端环境变量，不落客户端）
```

## 二、运行前准备（一次性，约 20 分钟）

1. **注册小程序账号**：https://mp.weixin.qq.com/ 注册（个人主体即可），拿到 **AppID**（本项目 `project.config.json` 已填入 AppID：`wxb5c70ce6f1f46ec0`，若用其他账号直接替换）
2. **安装微信开发者工具**：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html（Mac 版）
3. 用开发者工具打开本项目目录（AppID 已配置好，直接导入即可）
4. **添加同声传译插件**（语音输入用，免费）：
   - mp 后台 → 设置 → 第三方设置 → 插件管理 → 搜索添加「**微信同声传译**」（provider：wx069ba97219f66d99）
5. **开通云开发**：开发者工具 → 云开发 → 开通（免费额度即可）→ 记录**环境 ID**
6. `app.js` 里 `wx.cloud.init` 的 `env` 已填当前环境：`cloud1-d9ghre5sqc8a903fd`（换环境时改这里）

## 三、部署云函数并配置 Key

1. 开发者工具 → 云开发 → 云函数 → 右键 `chatProxy` → **上传并部署（云端安装依赖）**
2. 云开发控制台 → 云函数 → chatProxy → **配置** → **环境变量** → 添加：
   - 变量名：`DEEPSEEK_API_KEY`
   - 值：你的 DeepSeek API Key（只存在云端，客户端和小程序包内都没有）

## 四、本地预览与提审

1. 开发者工具点「编译」→ 模拟器内预览；手机扫码真机预览（真机需在工具里点「预览」）
2. 功能自测：按 `huiyilu/04-原型验收测试用例.pdf` 的 8 条用例过一遍
3. 提审前：
   - mp 后台填写**隐私协议**（麦克风、照片用途说明；文案参考仓库 docs/privacy-policy.md）
   - **小程序备案**：mp 后台 → 设置 → 小程序备案（流程与 App 备案类似，无服务器可走微信接入商通道）
   - AI 生成内容需在页面标注"内容由 AI 生成"（访谈回复底部已含产品名，如审核要求再加标注）
   - 个人主体可选「工具-效率」或「生活服务」类目

## 五、已知边界（二期规划）

- **语音朗读（TTS）**：微信无免费 TTS，二期接入讯飞/腾讯云 TTS（走云函数代理，Key 同样存云端）
- **方言识别**：同声传译插件目前以普通话识别为主，粤语/台语识别二期评估
- 会话历史本地暂存于页面内存，二期可加云数据库保存进度与"讲到哪儿了"
