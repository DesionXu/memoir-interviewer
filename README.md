# 📖 回忆录访谈员

一款专为老年人设计的 AI 回忆录访谈网页应用。老人只需开口说话，AI 访谈员会耐心倾听、逐个提问，把一生的故事慢慢聊出来，最后整理成一部留给后人的回忆录。

> 源码仓库：https://github.com/DesionXu/memoir-interviewer

## ✨ 功能特点

- **欢迎页**：输入网址即见优雅的欢迎页，点击"开启回忆录"进入访谈
- **大字体、简洁界面**：聊天文字 21px、按钮 24px，专为长辈设计
- **🎤 语音输入**：点一下麦克风说话，说完再点一下自动发送（边说边显示文字）
- **🔊 语音输出**：AI 的每次回复都会自动用中文语音朗读，语速稍慢
- **开关控制**：语音输入 / 语音输出均可一键开关
- **🎙️ 方言切换**：支持普通话、粤语（广东话）、台湾国语
- **📝 智能回忆录**：一键由 DeepSeek 把聊天素材整理成第三人称回忆录——开篇概要 → 目录 → 按时间线的正文，自动分页并标注页码；以老人原话为依据、不添油加醋，可在页面直接修改并下载为 txt 文件

## 🚀 使用方法（本地自用）

1. 把 `config.example.js` 复制一份并改名为 `config.js`，填入你自己的 DeepSeek API Key
2. 用 **Chrome 或 Edge** 打开 `index.html` → 欢迎页 → 点击"开启回忆录"
3. 首次使用语音输入时，允许浏览器使用麦克风

## 🌐 公网部署（推荐）

公网部署时 API Key **绝不能**放在前端文件里。本项目提供零依赖的后端代理 `server.js`（Node.js 18+）：

1. 把项目部署到服务器，创建 `.env` 文件（参考 `.env.example`）填入 API Key，或设置环境变量 `DEEPSEEK_API_KEY`
2. 启动：`node server.js`（默认 3000 端口，可用 `PORT` 环境变量修改）
3. 用 Nginx/Caddy 等反向代理到该端口并配置 HTTPS，访问你的域名即可

前端会自动通过同源 `/api/chat` 代理调用 DeepSeek，Key 只保存在服务器上，访客无法获取。也适合部署到 Railway / Render / Fly.io 等平台（把 `DEEPSEEK_API_KEY` 设为环境变量即可）。

## 🛠️ 技术说明

- **页面**：`index.html`（欢迎页）→ `memoir.html`（访谈页）
- **模型**：DeepSeek `deepseek-v4-pro`（Chat Completions API）
- **回忆录生成**：以老人讲述为唯一依据，第三人称、朴实家常的笔法重新撰写；单次输出被截断时自动续写补全，前端按章分页并标注页码
- **语音识别**：浏览器内置 Web Speech API（免费，需 Chrome / Edge）
  - 支持：普通话、粤语、台湾国语
  - 其他方言（四川话、上海话、闽南话等）需接入讯飞等商业语音服务
- **语音朗读**：浏览器内置 speechSynthesis，使用系统自带中文语音
- **后端**：`server.js`（可选，公网部署用，零依赖 Node 代理）

## ⚠️ 注意事项

- 公网部署务必使用 `server.js` 代理，不要把 `config.js` 或 API Key 放到公开服务器上
- `config.js`、`.env` 均已被 .gitignore 忽略，不会上传到仓库
- 语音识别依赖浏览器在线服务，需要联网；麦克风需要 HTTPS（localhost 除外）
