## 二、软件概述

本软件是一款面向中老年用户的 AI 回忆录访谈应用。用户以语音或文字方式讲述人生经历，AI 访谈员以问答形式耐心引导、逐段倾听，访谈结束后自动整理生成一部结构完整的回忆录（含开篇概要、目录与按时间线展开的正文），用户可修改、导出保存，将一生的故事留给后人。

## 三、主要功能

1. **AI 语音访谈**：点击麦克风开始语音输入，边说边显示文字，说完自动发送；AI 访谈员每次聚焦一个开放式问题，共情引导用户持续讲述。
2. **语音朗读**：AI 的每次回复自动用中文语音朗读，语速舒缓，可一键开关。
3. **方言支持**：语音识别与朗读支持普通话、粤语（广东话）、台湾国语。
4. **大字简洁界面**：字号、按钮专为长辈设计，操作简单直观。
5. **智能回忆录生成**：一键将访谈内容整理为第三人称回忆录——开篇概要、目录、按时间线分章的正文，自动分页并标注页码；以用户讲述为依据，不虚构情节。
6. **回忆录导出**：回忆录生成后可在线修改，并下载为 txt 文本文件保存。
7. **设置管理**：API 密钥本机加密存储；内置隐私政策说明。

## 四、运行环境要求

- 硬件：HarmonyOS NEXT 5.0 及以上系统的手机或平板
- 网络：使用 AI 对话、语音识别功能时需要联网
- 权限：麦克风（语音输入）、网络（AI 服务与语音服务）

## 五、操作说明

1. 启动应用，进入欢迎页；
2. 首次使用点击右上角"设置"，填入 DeepSeek API Key 并保存；
3. 返回欢迎页，点击"开启回忆录"进入访谈页；
4. 点击圆形麦克风按钮开始说话，说完再次点击自动发送；也可直接在输入框打字后点"发送"；
5. 可通过顶部开关控制语音输入/语音输出，通过下拉框切换方言；
6. 访谈结束后点击"生成回忆录"，稍候即可在文本框查看、修改；
7. 点击"下载回忆录"将文本文件保存到设备。
