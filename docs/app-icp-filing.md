# App 备案（ICP 备案）办理指南

> 依据 2023 年《工业和信息化部关于开展移动互联网应用程序备案工作的通知》，新上架 App 必须先完成备案。华为应用市场会要求提供备案号。

## 一、备案是什么

App 备案 = 移动互联网应用程序备案，与网站 ICP 备案同类。App 的**主办者信息**与服务器接入信息需要登记，由接入服务商（网络接入服务提供者）协助向省通信管理局提交。

## 二、办理前准备

| 材料 | 说明 |
|------|------|
| 主办者身份 | 个人：身份证（与开发者实名一致） |
| 手机号、邮箱 | 用于接收核验通知 |
| 应用信息 | 应用名称、图标、简介、功能说明、包名 |
| 网络接入信息 | 由接入服务商提供（见下） |

## 三、办理渠道（二选一）

**渠道 A：华为侧入口（推荐，与上架流程打通）**
- AppGallery Connect 创建应用后，在 AGC 后台 → 上架 → 会有"App 备案"入口，按指引填写并提交
- 华为提供接入辅助材料，无需自己先买服务器

**渠道 B：通过云服务商**
- 若你有服务器（如阿里云/腾讯云/华为云），在对应控制台提交 App 备案，获得备案号后填入 AGC

## 四、备案信息填写要点

- **应用名称**：与上架名称一致（"回忆录访谈员"）
- **应用服务内容**：生活服务类 / AI 语音访谈工具
- **是否含前置审批内容**：否（无新闻、出版、教育、医疗等前置审批内容）
- **网络接入服务商**：按所选渠道填写
- **服务器信息**（渠道 B 需要）：域名、IP、机房所在省份

## 五、时间与费用

- 时间：管局审核一般 **1-4 周**
- 费用：个人自办免费（部分服务商收取服务费）

## 六、常见问题

1. **没有服务器能备案吗？** 能。走华为 AGC 入口，华为提供接入信息辅助办理。
2. **备案号和软著可以并行办吗？** 可以，两者互不依赖，建议同时启动。
3. **备案通过后改包名/名称要重新备案吗？** 名称或主体变更需变更备案；建议定好名称和包名后再提交。
